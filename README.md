# PROG6212_POE_Part1

RaceDay event management system
## Project Description

RaceDay is an event management system designed to support the management of racing events and the participation of users in those events.The system provides functionality for organisers to manage events and for participants to interact with available racing events.

User Roles
## Organiser
The Organiser is responsible for managing racing events. Organiser functionality includes creating and managing event information and maintaining the information required for participants.

## Participant
The Participant interacts with racing events and can access relevant event information and participate in available events.
